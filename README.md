# 놀토 받쓰 클럽

워크샵용 유튜브 구간 받아쓰기 게임입니다.

게임 접속: https://dongantax-bomi.github.io/nolto-workshop-player/

로컬 서버나 파일 선택 없이 크롬에서 엽니다. 인터넷 연결이 필요합니다.

## 출제 구간

100곡 모두 가사 내용을 읽고 곡별로 벌스·랩·브리지를 선정했습니다. 25~35초 제한을 적용하지 않고 문맥과 단락을 우선합니다. 곡별 선정 이유는 플레이어와 구간선정_검토표.csv에 있습니다.

내용 검토와 실제 청취 검증은 구분합니다. 끝 시각은 싱크 가사의 단락 전환 또는 빈 가사 시각을 기준으로 정했으며, 전곡의 실제 가창 끝·마디·잔향을 청취 검증하지 않았습니다.

## 진행

- 곡 선택: 선정한 문제 구간 재생.
- 다시 듣기 / Space: 문제 구간 처음부터 재생.
- 일시정지: 현재 위치에서 정지.
- 이어서 재생: 멈춘 위치에서 계속 재생. 영상 재로딩이나 시작점 이동을 하지 않습니다.
- 정답 공개 / Enter: 정답 표시·숨기기.
- 검색·필터·랜덤 출제·팀 점수·발표 모드를 지원합니다.
- 시작/끝 시각과 정답은 진행자 설정에서 수정할 수 있습니다. 변경은 브라우저에 저장되며 JSON으로 옮길 수 있습니다.

## 음원 버전

recording_catalog.json에 실제 음원 제목·앨범·제공사·아티스트 자료를 고정했습니다. 일본 발매·타 언어·방송 편곡·반주·8D·리믹스 등을 검사합니다. 이는 발매 자료 대조이며 실제 청취 검증 표시는 아닙니다.

## 개발 및 배포

player.template.html은 화면 원본, songs_filled.json은 배포 데이터, section_overrides.json은 곡별 구간과 출처입니다. 원본 목록은 songs.csv입니다.

python prepare.py --rebuild
python -m unittest -v test_prepare test_curate
node test_playback.cjs
python validate_delivery.py
python build_site.py

main에 push하면 GitHub Actions 검사 후 Pages로 배포합니다. 준비 작업을 재실행할 때도 선정된 가사 자료와 음원 ID가 달라지면 임의로 같은 구간을 적용하지 않습니다.


## 내가 제일 잘 나가: 도입 후 문제 시작

4번은 2절로 변경했습니다. 도입 듣기는 97.64초에서 시작해 받쓰 직전에 자동 정지하고, 112.28초의 문제 시작 위치에 대기합니다. 설명 후 이어서 재생으로 112.28~142.08초의 랩 여덟 줄을 재생합니다. 다시 듣기는 도입 없이 문제만 반복합니다. 도입만 들은 상태에서는 사용한 문제로 표시하지 않습니다. 이 경계는 싱크 가사 기준이며 실제 음악적 경계 청취 검증은 별도입니다.
