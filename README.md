# 놀토 받쓰 클럽

제주 워크샵용 유튜브 구간 받아쓰기 게임입니다.

**게임 접속: https://dongantax-bomi.github.io/nolto-workshop-player/**

노트북에서 위 주소를 열고 곡을 선택하면 됩니다. Python 설치, 로컬 서버, 데이터 파일 선택이 필요 없습니다. 유튜브를 재생할 인터넷 연결과 크롬 브라우저를 준비하세요.

## 기능

- 연도·난이도·장르 필터, 가수·제목 검색
- 곡 클릭 후 지정 구간 재생과 자동 정지
- 다시 듣기, 정답 공개·숨기기, 영상 가리기
- 시작·끝 ±1초 조정, 정답 직접 편집, 브라우저 저장, JSON 백업
- 미사용 곡 랜덤 출제, 사용 기록, 두 팀 점수판
- 전체 화면 발표 모드와 키보드 단축키

원본 100곡 모두 공식 앨범 음원과 25~35초 싱크 가사 구간으로 준비했습니다. 전곡 청취 및 특정 멤버의 파트는 확인하지 않았습니다. [사용안내](사용안내.md)와 [검증결과](검증결과.md)를 참고하세요.

## 다른 노트북에서 진행하기

같은 웹 주소를 열면 내장된 곡 목록으로 바로 게임할 수 있습니다. 구간 수정·점수·사용 기록은 브라우저별로 보관됩니다. 다른 기기에 수정한 곡 설정을 가져갈 때만 JSON 내보내기/불러오기를 사용하세요.

## 수정 및 배포

`player.template.html`은 화면 원본이고 `songs_filled.json`은 곡 데이터입니다.

```sh
python prepare.py --rebuild
python -m unittest -v test_prepare test_curate
python validate_delivery.py
python build_site.py
```

main 브랜치에 변경 사항을 push하면 GitHub Actions가 데이터를 검증하고 GitHub Pages에 자동 배포합니다. 배포 과정에서는 외부 가사·유튜브 검색 API를 호출하지 않고 저장된 데이터를 사용합니다.

음원 자동 준비 재실행은 사용안내를 참고하세요. `.cache`, `.deps`, 로그, 환경변수 파일은 저장소와 배포에서 제외합니다.
