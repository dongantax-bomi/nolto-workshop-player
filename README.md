# 놀토 받쓰 클럽 · 6곡 워크샵

공개 실행: https://dongantax-bomi.github.io/nolto-workshop-player/

## 라운드

| 순서 | 곡 | 배점 |
|---|---|---|
| 1R | 다비치 · 타임캡슐 | 1점 |
| 2R | 볼빨간사춘기 · 여름아 부탁해 | 1점 |
| 3R | 보이넥스트도어 · 오늘만 I LOVE YOU | 1점 |
| 4R | 블랙핑크 · 뚜두뚜두 | 1점 |
| 5R | 빅뱅 · 붉은 노을 | 2점 |
| 연장 | 도경수 · 팝콘 | 1점 |

기존 100곡 중 뚜두뚜두만 원래 ID를 유지하고, 교체한 다섯 곡은 새 ID(101~105)를 씁니다. 화면에는 라운드 순서를 표시합니다. 예전 저장 기록의 삭제된 곡은 다시 복원하지 않습니다. 이전 100곡 JSON을 불러오는 것도 차단합니다.

## 사용

곡을 누르면 도입부터 받쓰 끝까지 연속 재생합니다. 진행자가 원하는 자리에서 일시정지를 누르고 설명한 뒤 옆의 이어서 재생을 누르면 그 자리에서 계속됩니다. 받쓰 시작 전 자동정지는 없습니다.

다시 듣기와 Space는 받쓰 구간만 반복합니다. 앞 구절까지 다시 들으려면 목록에서 곡을 다시 누르세요. 정답은 Enter 또는 정답 공개로 확인합니다. 붉은 노을을 선택하면 팀 점수에 +2 버튼이 나타납니다.

공식 앨범 음원 영상을 사용합니다. 인터넷과 YouTube 재생이 필요하며 광고 여부는 브라우저의 YouTube 로그인 및 이용 상태에 따라 달라집니다. 분석용 오디오와 모델은 .cache에만 저장하고 공개 사이트에는 올리지 않습니다.

## 구간과 검증

가사 의미가 이어지는 단락을 먼저 선정하고 분리 보컬의 에너지, 박자, 보조 음성 인식 시각으로 경계를 검토합니다. 자동 분석을 사람의 실제 청취 검증으로 표시하지 않습니다. 세부 근거는 section_overrides.json, audio_boundary_audit.json, 구간선정_검토표.csv에 기록합니다. 교체한 다섯 곡(101~105)은 싱크 가사 시각으로만 구간을 잡았고 오디오 분석은 하지 않았습니다. 여름아 부탁해는 lrclib에 시각이 없어 같은 길이 음원의 NetEase 싱크 가사 시각을 썼습니다.
